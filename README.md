# Balkh Dry Fruits Traders — Luxury B2B Website

A lightweight, responsive static website created for **Balkh Dry Fruits Traders** with the supplied logo.

## What is included

- Luxury green / gold / cream visual system
- Responsive mobile navigation
- Wholesale dry-fruit product portfolio
- Import / export trade model
- Quality & documentation section
- Business profile section with safe placeholders for GSTIN, FSSAI, IEC, address and email
- Wholesale enquiry form
- Supplied Balkh logo in `assets/balkh-logo.jpg`
- No framework or build step — works directly on GitHub Pages

## Before publishing

Replace the following placeholders in `index.html` and `script.js` with your **actual** information:

- Registered / business address
- Official business email
- Phone / WhatsApp
- GSTIN (only after registration)
- FSSAI licence number (where applicable)
- IEC number (for import/export activities)
- Any actual certifications or registrations

Do not publish invented registration numbers, warehouse addresses, certifications, customer names or shipment claims.

## GitHub Pages

This is a static site, so it can be published directly from a GitHub repository. GitHub Pages supports static HTML/CSS/JavaScript sites.

Typical flow:

1. Create a new GitHub repository, e.g. `balkh-dry-fruits-website`.
2. Upload `index.html`, `styles.css`, `script.js`, `assets/`, and this README.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch** and select the `main` branch and `/ (root)`.
5. Open the published Pages URL.

For a professional bank-facing presentation, connect a custom domain after the website content is verified.
